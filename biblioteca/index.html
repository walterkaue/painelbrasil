Material de estudo para quem opera Marketing Cloud.

Prompts, trilhas de certificação e guias em português, escritos por quem entrega projeto de Marketing Cloud em consultoria. Tudo aqui é aberto, tudo tem a fonte indicada, e tudo envelhece — por isso cada material carrega versão e data.

O que este acervo é: material genérico de plataforma. Conceito, método de estudo, mapa de certificação.

O que ele não é: nenhum material aqui contém dado, volumetria, nome, print ou configuração de cliente. Essa linha não é negociável, e é o motivo de este material poder ser público.

Sobre número: onde um dado tem uma fonte só, está escrito que tem uma fonte só. Onde não foi confirmado em fonte primária, está escrito também. Confira no Exam Guide oficial antes de marcar prova.

Antes de colar qualquer coisa num modelo

Os prompts deste acervo foram escritos para funcionar com cenário fictício. Isso é de propósito: contexto de cliente — nome, volumetria, estrutura de dados, copy aprovada, print de org — não entra em ferramenta de IA de uso geral. Se um prompt daqui só funcionar com dado real, ele está mal escrito e eu quero saber.

Achou um erro? Um número desatualizado, um nome de certificação que mudou, um prompt que não faz o que promete? Escreva. Correção confirmada vira versão nova do material, com a data trocada no registro de versão — não uma edição silenciosa.
